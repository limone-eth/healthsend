# H-71 — Link ready: a longer link, an exact end, and what's inside

## Story
- Right after making a link, the sender sees:
  - enough of the link to recognise it;
  - exactly when it stops working, down to the minute;
  - by name, which documents it holds.

## Operator requests, 2026-09-13 (screenshot of 2.5 Link ready after a two-minute, one-PDF share)
1. **"Truncate less chars in the link."**
   - `truncateLink` in `app/(sender)/new/page.tsx` cuts host+path at 26 characters, so the link row
     reads `healthsend.vercel.app/s/La…` with most of the row empty.
   - Show as much of host+path as fits the row at every width: CSS `truncate` on a flex child, not
     a fixed character count.
   - **Never show the `#` fragment.** It carries half the key, and `truncateLink`'s rule stays.
2. **"Make the when it ends more precise with minutes and date format."**
   - It reads "13 September 2026 · 2 minutes" for a share that ends two minutes from now.
   - Use `components/countdown-copy.ts` (already on main), the same wording as the recipient's
     Countdown: `endMoment` gives "today at 00:26" / "tomorrow at 09:15" / "Thursday at 18:00" /
     "4 December 2026".
   - Keep the length figure from the chosen window.
   - The sub-headline ("on 13 September 2026 it stops working") takes the same precision.
3. **"Remove the 'what they see about you' row, not needed."**
   - Delete the row and its `UserCircle` import if unused.
   - Drop the file-level comment's paragraph about that row.
4. **"Have the what's in it clickable to open accordion showing list of documents included."**
   - The "What's in it" row becomes a button with `aria-expanded`, a caret, and keyboard access.
   - Opening it lists every document in the link by its file name, with the PDF glyph and size.
     Use the same row style as the archive list.
   - Closed by default.
   - `SentSummary` does not carry names today, so pass them from the compose screen for both paths:
     archive-picked documents (`createSendFromArchive`) and freshly picked files (`createSend`).
   - Names stay on the sender's screen only. They must not go into the grant, the URL or anything
     the recipient receives beyond what already travels.

## Evidence
- **E2E at 1440 and 400, real clicks.** Use the existing link-ready path in the `/new` specs,
  stubbed as they already are:
  - the link row shows more than 26 characters of the path and never contains `#`;
  - "When it ends" contains a clock time for a short share;
  - no "about you" row;
  - clicking "What's in it" reveals every document name, and clicking again hides them;
  - zero horizontal overflow.
- **Red first:** each assertion fails against the current `page.tsx`.
