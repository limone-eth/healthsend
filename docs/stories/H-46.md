# H-46 — De-identification is wrong in both directions

## Story
- It leaves identifiers in, and it deletes medical content. The second is worse than doing nothing.

## Context
From review 2. Both high, both with direct probe output.

**R2-003 — identifiers survive.** Label-pattern values stop at a comma, and commas are part of
how names and dates are written. `Patient: Rivera, Jane` cleans to something still containing
`, Jane`. `DOB: March 14, 1988` still contains `, 1988`. `lib/deident.ts:24`.

**R2-004 — clinical content is destroyed.** Three separate heuristics overreach:

- Label values get no name validation, so `Patient: denies chest pain today.` is read as a name
  and removed. The probe returned `Plan: monitor` — the clinical statement gone.
- The top-of-document date heuristic treats any early date as a birth date, so
  `Collected: 2019-01-04` became `Collected: [set aside]` and the panel lost its collection date.
- Account-name removal has no word boundaries. With the account name `Ann`,
  `Annual physical review` became `[set aside]ual physical review`.

`lib/deident.ts:115`.

**Why R2-004 outranks R2-003 despite the same rating.** A missed identifier leaves the document
as disclosing as the sender's own file already was. A deleted lab date or a swallowed clinical
line changes what a clinician reads and cannot be noticed by the sender, who never sees the
cleaned output. A de-identifier that silently edits medicine is worse than one that does nothing,
and this one is about to be wired into the live send path by H-36.

## What to build
- Label values may contain commas. Names and dates are written with them.
- A label value must look like a name before it is treated as one. `denies chest pain today` does
  not.
- A date near the top of a document is not a date of birth merely for being near the top. Use the
  label, or leave it.
- Account-name removal respects word boundaries.
- Keep the four properties review 2 checked and found sound — the `Jordan Vance` letterhead and
  referral fixtures, the bare `14 March 1988` near the top, and scrubbing later occurrences
  across line breaks. Do not trade a false positive for a false negative.

## Evidence

The lane currently passes ten fixtures and caught none of this, so adding cases matters as much
as the fix.
