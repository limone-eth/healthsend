# H-9 — 2.5 Link ready

## Story
- The WeTransfer moment: the link, what is in it, who can open it, when it ends, and what it says
  about her.

## Context
Depends on: H-4.
Design: `LKFS1` (desktop), `uQP20` (mobile).

The four summary rows are drawn and worded: *What's in it · Who can open it · When it ends ·
What she sees about you*.

The link is 98 characters as of 2026-09-12 and the frame shows it truncated with a copy control.
Keep it truncated — a full-width URL on screen invites someone to retype it, and the fragment
after `#` is half the key. Copy puts the whole thing on the clipboard.

`x9IoK` on the frame reads *"Changed your mind? End it early from Your shares and she loses
access straight away."* That sentence is **now true** and was not before — it depends on H-11, so
either land H-11 first or ship this story without that line.

## Reading the design

**`healthsend.pen` is the source. A screenshot of it is not.** Read the nodes with the
`mcp__pencil__execute` tool against `<repo>/healthsend.pen`:

```js
Print(JSON.stringify(Get("<a frame id named in this story>", {depth: 6}), null, 1))
```

- `Get(id, {depth: n})` returns exact geometry, fills, strokes, corner radii, gaps, padding, font
  family, size and weight — and the `$token` references **by name**. None of that survives a
  screenshot, and guessing it is how a build ends up approximately right and visibly off.
- Add `resolveInstances: true` to expand component instances; the ids that come back are
  `instanceId/childId` paths you can read further.
- `Get(id, (n, c) => Print(n.name, c.bounds.width, c.bounds.x))` gives resolved bounds in the
  parent's coordinate space. Use it to check alignment and spacing rather than measuring pixels by
  eye. `c.problems` flags anything clipped by its parent.
- **Copy every string verbatim from the `content` fields.** Re-typing copy from an image is how a
  claim that was deliberately corrected gets silently restored — that has already happened once in
  this project, which is why H-20 says so explicitly.
- `TakeScreenshot([id])` is for confirming your build matches after you have read the nodes. It is
  never the input.

**Read only.** Never call `Insert`, `Update`, `Copy`, `Replace`, `Delete`, `Move`, `SetVariables`
or `Generate` against the canvas, and never commit `healthsend.pen`. The pencil MCP server drives
the operator's live editor, not your worktree's copy of the file — a write from a worker lands in
their open document. The design is an input to this story and an output of none.

Node ids named in this story are stable and can be read directly. The frame is the contract; where
this story's prose and the frame disagree, read the frame and say so in `## Choices`.

**Routing:** this story needs a worker whose engine has the `pencil` MCP server. It is configured
globally on this machine, so a Claude worker in a worktree inherits it; an engine without it can
only see exported images and must not be given this story.
