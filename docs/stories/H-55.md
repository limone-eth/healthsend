# H-55 — Say what this is, and what it is not

## Story
- Document the PoC without letting a reader believe it is a product, and re-check every claim the
  new path touches.

## Context
Task 8 of the TACo PoC plan. Depends on H-54.

This repository has shipped **six** false claims about personal data and caught them late every
time. The TACo path introduces a new set of things it would be easy to say and wrong to mean.

## What to build
`README.md` and `.env.example`: run instructions, evidence language, and the current TACo
infrastructure warning.

**Three sentences that must appear, and must stay true:**

1. Previously delivered keys and plaintext remain usable. Expiry blocks *new* unlocks.
2. TACo is not currently a supported production dependency.
3. Nothing here is secure erasure, recipient identity, or a decentralized service in operation.

Then re-check the claims this path touches, including `components/sign-in-screen.tsx`'s "we hold
no copy of your health data" — already owed a rewrite by H-22 — and anything on `/landing` that
the screens audit flagged.

## Non-goals
- Claiming production readiness in any form.
