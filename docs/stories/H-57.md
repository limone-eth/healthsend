# H-57 — Import misreads blanks, ranges and flags

## Story
- A blank reading becomes a clean zero, a qualified reading vanishes, and an impossible reference
  range reads as a clean match. On a screen whose whole job is "did we read this right".

## Findings (review 3)
- **R3-018 (high)** `lib/import.ts:96` — blank readings become clean zero values; qualified
  readings (`<5`, `>100`) disappear. A zero TSH is a clinical claim, not an absence.
- **R3-002 (high)** `lib/import.ts:99` — invalid reference ranges (min > max, non-numeric) are
  presented as clean matches instead of flagged as parse uncertainty.
- **R3-019 (medium)** `scripts/archive-roundtrip.mjs:47` — no proof protects `labFlag` surviving
  into scoped records, so H-38's fix can regress silently on the share path.
- **R3-014 (low)** `scripts/import-flag-proof.mjs:63` — the demo still does not use the fixed
  32-marker dataset.

## What to build
A blank value is **missing**, never zero — flag it. A qualified reading keeps its qualifier as data.
An invalid range is parse uncertainty and flags. `labFlag` is asserted end to end through
`scopeArchive`. Every probe above becomes a fixture demonstrated red first.

## Non-goals
- The send path (H-58) and scope selection UI.
