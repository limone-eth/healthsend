# H-49 — The two routes outside the sender group destroy the Swarm ID iframe

## Story
- `/add` and `/import-review` render `SenderChrome` but live outside `app/(sender)/`, so they never
  get the layout that keeps the connect container mounted.

## Context
**R2-006 — high.** `CLAUDE.md` names this as one of the five things that will bite: *"The Swarm ID
container must stay mounted. It is rendered in every state, signed in or out. Unmounting it
destroys the iframe and every later call fails with 'Iframe not initialized'."*

`app/(sender)/layout.tsx` mounts `CONNECT_CONTAINER_ID` unconditionally and H-21 made that
invariant explicit in code. But `app/add/page.tsx:233` and `app/import-review/page.tsx` import
`SenderChrome` directly and sit at the app root, outside the route group — so navigating to either
unmounts the container that the sender layout was holding. The rail links to both.

**Also in scope, all smaller, all from review 2:**

- **R2-016 — medium** — an invalid custom expiry silently falls back to a different window, so the
  sender is told one date and gets another. `app/(sender)/new/page.tsx:133`.
- **R2-018 — medium** — parsed rows are not bound to their raw source rows, so "in your file"
  can show the wrong line. `app/import-review/page.tsx:71`.
- **R2-019 — medium** — the contrast guard skips all gradient-backed text, which is most of the
  inverted 3.4 surface. `e2e/contrast.spec.ts:73`.
- **R2-021 — low** — verify before fixing: the recipient countdown was reported as showing seconds
  and minutes, but H-5 replaced `timeLeft` with the `Countdown` primitive on that screen. Check
  whether it still reproduces, and if `timeLeft` now has no caller, say so.
- **R2-024 — low** — the Lua proof does not test command-level script errors.
  `scripts/access-log-proof.mjs:310`.

## What to build
Bring `/add` and `/import-review` under a layout that keeps the container mounted — moving them
into `app/(sender)/` is the obvious shape, but check what the route change costs before assuming
it. Then the five smaller fixes.

## Evidence
For R2-006: sign in, navigate to `/add` via the rail, and make a Swarm ID call. It must not fail
with "Iframe not initialized". Every other item gets a test that fails first.
