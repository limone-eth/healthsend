# H-50 — The key-release boundary, and a package that cannot be re-aimed

## Story
- Before any TACo code exists, define what a threshold release *is* to this codebase, and make a
  grant's protected key share bind to exactly one grant.

## Context
Task 1 of the TACo PoC plan (`~/Desktop/healthsend-taco-expiry-poc-plan.md`). This story is
deliberately provider-neutral: TACo has **no supported network right now** — its own SDK docs warn
of no stable operator cohort and no mainnet infrastructure, relaunch planned Q3 2026 — so the
release mechanism must be replaceable without touching anything above it.

The scope for the whole PoC is one **blood-test PDF**, uploaded once and shared. Per-file,
per-marker and per-date encryption inside the asset is deferred; the format must not forbid it.

## What to build
- `lib/key-release/types.ts` — `KeyReleaseProvider`, provider-neutral. No TACo import anywhere in
  this file.
- `lib/grant-package.ts` — `GrantBinding`, `ProtectedKeyShare`, `protectGrantShare`,
  `releaseGrantShare`.
- `lib/crypto.ts` — domain-separated capsule wrapping and AEAD additional-data helpers. Do not
  disturb the existing split-key functions; `verify:crypto` must stay green.
- **The binding is the point.** A protected share must carry the random grant id, the native Arkiv
  owner and the original native expiry block, authenticated as additional data. A package built
  for grant A must be unusable against grant B, and a caller must not be able to substitute a
  different live entity for an expired one.
- **Wrap the capsule under a link-derived key too.** Grant payloads are public. A capsule
  protected only by the release rule lets a crawler collect every live grant's held share before
  its deadline and decrypt afterwards. Two locks: the link to see it, the release rule to open it.

## Evidence
`scripts/taco-package-proof.mjs`, offline, with a fake provider that records bindings and refuses
an expired release. It must prove: the binding is what was recorded; a package cannot be opened
against another grant; an expired release yields nothing; and no key material touches
localStorage, sessionStorage, IndexedDB or any cache.

## Non-goals
- Any TACo import. That is H-52.
- Touching `lib/sends.ts` or Arkiv. Those are H-51 and H-53.
