# H-35 — Three user-facing claims I wrote today are false
## Story
- A revoked send tells the recipient *"Nobody revoked this."* The sender's page promises a deletion
  that happens up to an hour later than stated. The demo notice describes a bearer link as though
  only two people can open it.

## Context
From the adversarial review. All three are on orchestrator commits made this session — while
correcting four *other* false claims. Recorded plainly, because that is the pattern worth noticing:
each was written quickly, on the way to something else, and none was checked against the code.

**1. Critical — `app/s/[key]/page.tsx:265`.** A revoke and a natural expiry both produce a missing
share, which `lib/unlock.ts:92` maps to `expired`. The expired page then says *"Nobody revoked
this. No job ran. The access simply ran out."* When the sender did revoke, every clause of that is
false. The two states need distinguishing, or the copy must stop asserting which one happened.

**2. High — `app/page.tsx:80`.** *"When the window closes, the half of the key we hold is deleted."*
`putShare` adds `TTL_GRACE_SECONDS` (one hour), deliberately, so the holder's TTL never undercuts
the window the sender was promised. The grace period is right; the sentence overstates its
precision. I wrote this while correcting *"Then the key is gone"*, which was worse — but replacing
one imprecise claim with another is not the job.

**3. Medium — `components/demo-notice.tsx:28`.** *"only you and whoever you send the link to can
open them."* The link is a transferable bearer capability: anyone the recipient forwards the whole
URL to can open it, with no identity and no device binding. I wrote that sentence in response to
feedback that the notice overstated the risk — and overcorrected into overstating the safety. H-7's
PIN and claim-on-first-open are what would make it true.

## What to build
Three copy changes, each checked against the code path it describes. Note that (1) may need a state
distinction rather than only new words, and that (3) becomes true — not just better worded — when
H-7 lands.
