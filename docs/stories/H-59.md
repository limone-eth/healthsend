# H-59 — The Playwright server fix still has two holes

## Story
- The fold-time fix that stopped worktrees silently testing another checkout's server is incomplete.
  Review 3 reviewed it because no story covered it and no worker wrote it.

## Findings (review 3)
- **R3-004 (high)** `playwright.config.ts:56` — `BASE_URL` still turns reuse on, so pointing it at a
  port another checkout holds attaches to that checkout, reproducing the original bug.
- **R3-017 (medium)** `playwright.config.ts:41` — a base URL with no port or with `https` derives a
  port that starts an incompatible local server.

## What to build
Reuse only when the server provably belongs to this checkout, or refuse. Handle default-port and https
URLs explicitly. A test per form: no-port, https, a port held by a foreign process — each must either
start the right server or fail loudly.

## Non-goals
- Changing any spec's assertions.
